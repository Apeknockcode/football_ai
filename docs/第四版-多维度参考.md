# 第四版 · 多维度参考（多网站联赛数据）

联赛历史数据与赛前预期 xG 不再只依赖单一网站（如仅 Understat），可**同时参考多个数据源**（如 Understat + FBref），用于校准、回测与报告。

---

## 1. 目标

- **联赛多源**：同一联赛可配置 Understat、FBref 等来源，抓取后合并或对比使用。
- **近期赛季**：2025/26 赛季（含 2026 年 1–2 月比赛）在 Understat 与 FBref 上通常都有部分赛程与 xG，可同时抓取、互为参考。
- **校准/回测**：历史数据可来自「主源 + 辅源」合并（如 xG 取平均或主源优先），提高稳健性。

---

## 2. 数据源与 2026 年 1–2 月

| 来源       | 联赛覆盖                     | 2025/26（2026 年 1–2 月） |
|------------|------------------------------|----------------------------|
| **Understat** | EPL、西甲、德甲、意甲、法甲等 | 当前赛季会逐步更新，常有 1–2 月数据 |
| **FBref**     | 五大联赛 + 英冠等，comp 见下 | 赛程页含 2024–2025、2025–2026，1–2 月会更新 |

同一联赛在两站都有时，可：

- 分别抓取：`./run.sh fetch EPL 2026`（Understat）、`./run.sh fetch fbref EPL 2026`（FBref）
- 合并为统一 `pl_2026.csv`：`./run.sh merge EPL 2026`（见下文）

---

## 3. 联赛 FBref 配置（config/leagues.yaml）

在 `config/leagues.yaml` 中为联赛增加可选字段：

- **fbref_comp_id**：FBref 赛事 ID（如英超 9、西甲 12）
- **fbref_slug**：赛程 URL 片段（如 `Premier-League`、`La-Liga`）

常用对应关系：

| 联赛 id     | FBref comp_id | fbref_slug     |
|-------------|----------------|----------------|
| EPL         | 9              | Premier-League |
| Championship| 10             | Championship   |
| Serie_A     | 11             | Serie-A        |
| La_Liga     | 12             | La-Liga        |
| Ligue_1     | 13             | Ligue-1        |
| Bundesliga  | 20             | Bundesliga     |

德乙、法乙、荷甲、沙特联等若 FBref 有对应 comp，可按需在配置中补充；无则留空，仅用 Understat 或手工数据。

---

## 4. 目录与文件约定

- **单源历史**（保留原始来源，便于对比）  
  - Understat：`data/historical/{league_id}/pl_YYYY.csv`（或 `pl_YYYY_understat.csv`）  
  - FBref：`data/historical/{league_id}/pl_YYYY_fbref.csv`
- **合并结果**（校准/回测默认使用）  
  - `data/historical/{league_id}/pl_YYYY.csv`  
  由 `./run.sh merge {league_id} {season}` 根据「主源 + 辅源」生成（如 xG 取平均）。

---

## 5. 合并策略（多源 → 单表）

合并脚本根据 `(season, round, home_team, away_team)` 匹配同一场比赛：

- 若两源都有该场：`xg_home` / `xg_away` 可取**平均**，或配置为「主源优先、辅源补缺」。
- 若仅单源有：直接采用该源进球与 xG。
- 队名不一致时：可用 `config/team_name_mapping.*.csv` 做归一化（与现有报告/预期 xG 映射一致）。

合并后 CSV 格式与现有一致：`season, round, home_team, away_team, xg_home, xg_away, goals_home, goals_away`。

---

## 6. 使用示例

```bash
# 拉取 EPL 2025/26（含 2026 年 1–2 月）Understat
./run.sh fetch EPL 2026

# 拉取同一联赛、同一赛季 FBref
./run.sh fetch fbref EPL 2026

# 合并两源为 pl_2026.csv（用于校准/回测）
./run.sh merge EPL 2026

# 校准与回测仍按联赛、仍读 pl_YYYY.csv
./run.sh calibrate --league EPL
./run.sh backtest --league EPL
```

其他联赛同理（La_Liga、Bundesliga、Serie_A、Ligue_1、Championship 等），只要在 `leagues.yaml` 中配置了 `understat_code` 和/或 `fbref_comp_id` 即可。

---

## 7. 与第三版的关系

- **第三版**：多联赛、多杯赛、按联赛/杯赛校准与抓取。  
- **第四版**：在第三版基础上，**联赛维度**支持多数据源（Understat + FBref），抓取与合并脚本扩展，配置增加 FBref 字段；杯赛仍仅 FBref，不变。

校准、回测、报告逻辑不变，仅「历史数据从哪里来」扩展为可多源合并。

---

## 8. FotMob（soccerdata 免费库）

已通过 **soccerdata** 接入 **FotMob** 作为第三数据源：

- 配置：`config/leagues.yaml` 中为联赛设置 **fotmob_league_id**（如 `ENG-Premier League`、`ESP-La Liga`）。
- 抓取：`./run.sh fetch fotmob EPL 2026` → 输出 `data/historical/EPL/pl_2026_fotmob.csv`。
- 合并：`./run.sh merge EPL 2026` 会同时合并 Understat、FBref、FotMob（若存在），同场 xG 取多源平均。

依赖：`pip install soccerdata`（已写入 requirements.txt）。

## 9. 其他可抓取数据源

除 Understat、FBref、FotMob 外，还有 Sofascore、ESPN、WhoScored 等可作补充；付费 API 见说明。详见 **[其他可抓取数据源.md](其他可抓取数据源.md)**。
