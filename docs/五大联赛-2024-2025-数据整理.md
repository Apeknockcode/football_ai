# 五大联赛 2024–2025 年数据整理

## 〇、合并模型（Combined）

五大联赛数据可合并为统一大样本，用于**统一校准**与回测：

```bash
# 合并五大联赛 → data/historical/Combined/
./run.sh merge-five

# 生成 Combined 校准（基于 ~3500 场）
./run.sh calibrate --league Combined

# 回测 Combined 模型
./run.sh backtest --league Combined

# 生成报告时使用 Combined 校准
./run.sh pre --league Combined --home 阿森纳 --away 切尔西 --round 15
```

合并后校准参数代表五大联赛整体分布，可作为通用模型；单联赛校准则更贴合该联赛风格。

| 模型 | 场次 | 胜负平命中率 | 最可能比分 | Top-3 比分 |
|------|------|--------------|------------|------------|
| Combined（五大联赛合并） | 3504 | 68.9% | 32.8% | 53.7% |
| EPL 单联赛 | 1380 | 57.9% | 21.0% | 41.7% |

## 三、常用命令

```bash
# 拉取五大联赛 2024、2025 年数据（Understat）
./run.sh fetch all 2024 2025

# 为指定联赛校准
./run.sh calibrate --league EPL
./run.sh calibrate --league La_Liga
./run.sh calibrate --league Bundesliga
./run.sh calibrate --league Serie_A
./run.sh calibrate --league Ligue_1

# 回测
./run.sh backtest --league EPL
./run.sh backtest --league La_Liga
# ... 其他联赛同理

# 生成赛前报告（需指定联赛以用对应校准）
./run.sh pre --league EPL --home 阿森纳 --away 切尔西 --round 15
./run.sh pre --league La_Liga --home 巴萨 --away 皇马 --round 10
```

## 四、数据来源与更新

- **主数据源**：Understat（`./run.sh fetch all 2024 2025`）
- **可选多源合并**（第四版）：
  - FBref：`./run.sh fetch fbref EPL 2025`
  - FotMob：`./run.sh fetch fotmob EPL 2025`
  - 合并：`./run.sh merge EPL 2025`
