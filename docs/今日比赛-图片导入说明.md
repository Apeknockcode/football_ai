# 今日比赛：图片导入与批量预测

## 一、流程概览

1. **提供比赛图片**（如 bisai.png）：含联赛、场次号、主客队、让球数
2. **整理为 CSV**：放入 `data/YYYY-MM-DD/todays_matches.csv`（以当前年月日为文件夹前缀）
3. **运行批量预测**：`./run.sh predict-today`
4. **查看结果**：`data/YYYY-MM-DD/todays_predictions.csv` 或终端输出

所有今日相关文件均存放在 `data/YYYY-MM-DD/` 目录下，例如 `data/2026-02-08/`。

## 二、todays_matches.csv 格式

| 列名 | 说明 | 示例 |
|------|------|------|
| match_id | 场次号 | 15 |
| league_id | 联赛 id | EPL, La_Liga, Serie_A, Bundesliga, Ligue_1, Eredivisie, Combined |
| league_zh | 联赛中文 | 英超, 西甲 |
| home_team | 主队（中文） | 富勒姆 |
| away_team | 客队（中文） | 埃弗顿 |
| round | 轮次 | 15 |
| handicap_note | 让球数 | -1（主让1）, +1（主受让1）, -2（主让2） |
| xg_home | 可选，主队预期 xG | |
| xg_away | 可选，客队预期 xG | |

## 三、预期 xG 来源

- 未填 xg_home/xg_away 时，从 `data/expected_xg_teams.csv` 按球队匹配
- 表格式：`team,xg,xg_home,xg_away`（队名与 home_team/away_team 一致）
- 可从 Understat 等站更新各队 xG

## 四、伤停（可选）

- 在 `data/YYYY-MM-DD/todays_injuries/` 放入 CSV：`team, player, reason`
- 有伤停时会微调预期 xG

## 五、命令

```bash
# 批量预测（默认用 data/YYYY-MM-DD/todays_matches.csv，当天日期）
./run.sh predict-today

# 指定日期目录
./run.sh predict-today --date 2026-02-07

# 指定其他赛程文件
./run.sh predict-today data/2026-02-08/custom_matches.csv
```

首次运行时会自动创建当天日期目录；`expected_xg_teams.csv` 仍在 `data/` 根目录作为共享参考。

## 六、输出说明

- **主胜/平/客胜**：胜负平概率
- **最可能比分**：模型预测最可能结果
- **让胜/让平/让负**：按 handicap_note 对应的让球概率

葡超、荷甲等无单独校准时，使用 Combined 校准。
