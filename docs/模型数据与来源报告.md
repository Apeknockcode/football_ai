## 三、数据管道概览

| 阶段 | 说明 | 脚本/命令 |
|------|------|-----------|
| 抓取 | 从 Understat 拉取五大联赛 xG+赛果 | `./run.sh fetch all 2024 2025` |
| 抓取 | 单联赛 Understat | `./run.sh fetch EPL 2025` |
| 抓取 | FBref、FotMob 等辅源 | `./run.sh fetch fbref EPL 2025` |
| 合并 | 同联赛多源合并 | `./run.sh merge EPL 2025` |
| 合并 | 五大联赛汇总 | `./run.sh merge-five` |
| 校准 | 生成 calibration_*.yaml | `./run.sh calibrate --league EPL` |

## 四、外部数据源

| 来源 | 网站 | 用途 |

| Understat | understat.com | 五大联赛 xG、赛果（主源） |
| FBref | fbref.com | 五大联赛、杯赛 xG、赛果 |
| FotMob | soccerdata 库 | 联赛 xG、赛果 |
| WhoScored | 需 Selenium | 联赛 xG、赛果 |
| Football-Data.co.uk | football-data.co.uk | 赛果、赔率（无 xG） |
