# 如何添加至少一季英超历史场次

用于**校准**与**回测**，必须先有历史表，才能回答「预测准确性多高」。一季英超约 380 场（20 队 × 19 主客 × 2），至少需要每场的：**主客队、轮次、主客 xG、主客实际进球**。

---

## 一、表长什么样（必选列）

在 `data/historical/` 下放 CSV，**表头与列名必须一致**（UTF-8 编码）：

| 列名 | 说明 | 示例 |
|------|------|------|
| season | 赛季年（结束年） | 2024 |
| round | 轮次 | 1 |
| home_team | 主队名（与报告用名一致，如中文） | 曼联 |
| away_team | 客队名 | 富勒姆 |
| xg_home | 主队该场 xG | 1.8 |
| xg_away | 客队该场 xG | 1.2 |
| goals_home | 主队实际进球 | 2 |
| goals_away | 客队实际进球 | 1 |

可选列：`ht_goals_home`、`ht_goals_away`（半场比分，用于后续半全场评估）。

**示例一行**：
```csv
season,round,home_team,away_team,xg_home,xg_away,goals_home,goals_away
2024,1,曼联,富勒姆,1.8,1.2,2,1
```

可单文件如 `pl_2024.csv`，也可多文件如 `pl_2023.csv`、`pl_2024.csv`，程序会读取本目录下所有 `.csv`。

---

## 二、数据从哪来

### 1. Understat（understat.com）

- 打开 [Understat 英超](https://understat.com/league/EPL)，选赛季（如 2024）。
- 页面有每场**赛果 + xG**（主客 xG、比分），有时需点进单场或导出。
- 若网站提供**按场次列表/导出**，可导出后按下列名改成：`season, round, home_team, away_team, xg_home, xg_away, goals_home, goals_away`；队名建议统一成你报告里用的中文名（或英文名 + 用 `config/team_name_mapping.example.csv` 映射）。
- 若无一键导出，只能**逐场抄写或自己写脚本抓取**（注意网站条款与访问频率）。

### 2. FBref（fbref.com）

- 进入 Premier League → 该赛季 → 赛程/结果，通常有每场比分与部分高级数据。
- 若有 xG 列，可导出 CSV 后重命名列为上表列名，队名同样建议与报告一致（中文或映射）。

### 3. 其他数据源

- 任何有「每场主客 xG + 实际比分」的数据源（API、Excel、付费数据）都可以，只要整理成上述 CSV 列名与编码（UTF-8），放进 `data/historical/` 即可。

---

## 三、操作步骤（简要）

1. **选一季**  
   例如 2023/24 赛季，则 `season=2024`，所有该季场次同一 `season`。

2. **拿到每场 8 个字段**  
   season, round, home_team, away_team, xg_home, xg_away, goals_home, goals_away。  
   可从 Understat/FBref 等导出或手工整理。

3. **统一队名**  
   与你在报告/预期 xG 里用的名字一致（如全用中文：曼联、富勒姆、利兹联、诺丁汉森林 等），避免校准/回测时对不上。

4. **存成 CSV**  
   - 编码：**UTF-8**  
   - 路径：`data/historical/EPL/pl_2024.csv`（或你自定义文件名，只要在 `data/historical/EPL/` 下且为 `.csv`；其他联赛用对应 `data/historical/{league_id}/`）。

5. **跑校准与回测**  
   ```bash
   # 从历史数据生成校准参数（会覆盖 config/calibration_pl.yaml）
   python scripts/calibrate_pl.py

   # 用历史场次回测，看 Brier、平均对数似然
   python scripts/backtest_pl.py
   ```
   这样就有「至少一季」的准确性参考。

---

## 四、最小可用的量

- **至少一季**：建议整季 380 场，校准时更稳。
- 若暂时拿不到整季，可先放**几十场**（如某一轮次或某几轮），先跑通校准与回测流程，再逐步补全；样本越少，校准参数和准确性指标越不稳定。

---

## 五、模板 CSV（可直接复制表头）

在 `data/historical/` 下新建 `pl_2024.csv`，首行贴下面这一行，下面每行一场比赛：

```csv
season,round,home_team,away_team,xg_home,xg_away,goals_home,goals_away
```

然后按 Understat/FBref 等来源，一行行补全 8 列即可。
