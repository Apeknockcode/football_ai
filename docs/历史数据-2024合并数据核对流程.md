# 2024 合并数据 · 自动化核对流程

用于在换源或合并后，**自动化核对** `data/historical/Combined/pl_2024.csv` 是否满足基本正确性，便于在用于校准/回测前发现问题。

---

## 一、何时执行

- 每次用 FBref HTML 换源并执行 `./run.sh merge-five` 之后。
- 或手工修改过各联赛 `pl_2024.csv` / Combined 之后，希望快速自检。

---

## 二、执行方式

在项目根目录执行：

```bash
./run.sh validate-data --merged-2024
```

或直接：

```bash
python3 scripts/validate_historical_data.py --merged-2024
```

可选：与**参考样本**逐条比对比分（见下文「参考样本」）：

```bash
python3 scripts/validate_historical_data.py --merged-2024 --ref data/historical/_common/validation_ref_2024_sample.csv
```

---

## 三、核对项说明

脚本会对 **Combined/pl_2024.csv** 做以下检查，全部通过则输出「全部通过」。

| 核对项 | 说明 | 不通过时处理建议 |
|--------|------|------------------|
| **场次数量** | 各联赛场次在预期范围：英超/西甲/意甲 376–384（约 380），德甲/法甲 302–312（约 306） | 检查来源 HTML 是否完整、replace 脚本是否过滤了非正赛表格 |
| **无重复场次** | 同一联赛、同一轮、同一主客对仅出现一次 | 去重或检查解析逻辑 |
| **轮次范围** | 20 队联赛 round 在 1–38，18 队联赛 round 在 1–34 | 若出现 300+ 的 round，多为 FBref 其他表格被误解析，已在 replace 脚本中按 max_round 过滤 |
| **比分与 xG 范围** | 比分 0–15，xG ≥ 0 且 ≤ 10 | 修正异常行或数据源 |
| **与参考 CSV 比对** | 使用 `--ref` 时，参考文件中每场的比分与合并数据一致 | 以权威来源修正合并数据或更新参考文件 |

---

## 四、参考样本（可选）

可用「参考 CSV」记录一批**已与权威来源核对的比分**，用 `--ref` 做逐场 diff，防止后续换源或误改把正确比分覆盖掉。

- **格式**：CSV，表头至少包含  
  `league, home_team, away_team, goals_home, goals_away`  
  列名需与合并数据一致（如主客队名、联赛 id）。
- **示例文件**：`data/historical/_common/validation_ref_2024_sample.csv`  
  内含少量示例（如拜仁–勒沃库森两场、英超两场），可按需增删行。
- **扩充方式**：从联赛官网、ESPN、Transfermarkt 等核对若干场，把结果追加到该 CSV，再运行  
  `python3 scripts/validate_historical_data.py --merged-2024 --ref data/historical/_common/validation_ref_2024_sample.csv`  
  若存在比分会差，脚本会列出「数据=… 参考=…」。

---

## 五、与「定义与清洗」的关系

- 本流程是**自动化结构/数量/范围 + 可选样本比对**，不能替代 [历史数据-定义与清洗.md](历史数据-定义与清洗.md) 中的**来源标注、match_date 建立、逐条核对比分**。
- 建议顺序：**先换源 → 跑本核对流程（通过）→ 再按定义与清洗做来源/日期/比分深度核对**，用于校准与回测前再跑一次 `--merged-2024`（及 `--ref`）做最后确认。

---

## 六、其他校验

- **无效场次统计**（不传 `--merged-2024`）：  
  `./run.sh validate-data`  
  会扫描各联赛目录，统计「0–0 且 xG 全 0」的疑似未开赛/缺数据场次，供人工判断是否需补数据或排除。
