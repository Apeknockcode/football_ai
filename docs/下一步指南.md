# 下一步指南

不知道怎么做时，按下面顺序来即可。

---

## 一、日常：今天/某天要做预测

任选一种方式，**做完一步就得到当日预测结果**。

### 方式 A：命令行一键（推荐）

在项目根目录执行（Key 已写在 `config/odds_api_key.txt` 时无需再设置环境变量）：

```bash
./run.sh today-full
```

或指定日期：

```bash
./run.sh today-full --date 2026-02-10
```

会自动完成：拉取当日五大联赛赛程 → 拉取盘口 → 批量预测。结果在 `data/<日期>/todays_predictions.csv`。

### 方式 B：用桌面应用

1. 打开桌面：在 `desktop/` 下执行 `npm run dev`。
2. 进入「今日预测」页，选好日期。
3. 点 **「获取今日五大联赛」** → 表格会填上当日赛程。
4. 点 **「拉取盘口」**（会读 `config/odds_api_key.txt`）。
5. 在「预测源」里选 Poisson / ML / 融合，点 **「运行预测」**。
6. 看下方日志和结果；预测结果会写入 `data/<日期>/todays_predictions.csv`。

### 方式 C：分步命令行

```bash
# 1) 拉赛程（写入 data/<日期>/todays_matches.csv）
.venv/bin/python scripts/fetch_todays_fixtures.py --date 2026-02-10

# 2) 拉盘口（合并进同一 CSV，需 config/odds_api_key.txt）
.venv/bin/python scripts/fetch_odds.py --date 2026-02-10

# 3) 预测（结果写 data/<日期>/todays_predictions.csv）
.venv/bin/python scripts/predict_batch.py data/2026-02-10/todays_matches.csv \
  --out data/2026-02-10/todays_predictions.csv --historical data/historical
```

## 二、想提高预测质量时（可选）

| 你想… | 怎么做 |
|--------|--------|
| 用上赛前预期 xG（而不是默认 0.5） | 准备按球队的 xG 表（见 `data/expected_xg/README.md`），用 `--expected-xg` 指向该表；或运行 `scripts/fetch_expected_xg_understat.py` 拉取后给 `predict_batch` 用。 |
| 考虑伤停 | 在 `data/<日期>/todays_injuries/` 下放伤停 CSV（列：team, player, reason），预测时会自动微调 xG。 |
| 调盘口权重 | 改 `config/settings.yaml` 里 `predictions.odds_blend_weight`（0～1，如 0.2 表示 20% 盘口）。 |
| 看历史表现 | 运行 `./run.sh backtest [--league EPL]` 做回测。 |

## 三、常用文件位置

| 内容 | 路径 |
|------|------|
| 当日赛程（可含赔率） | `data/<日期>/todays_matches.csv` |
| 当日预测结果（含最可能/次可能/第三可能比分，Poisson 或融合时有详情） | `data/<日期>/todays_predictions.csv` |
| 盘口 API Key（勿提交 Git） | `config/odds_api_key.txt` |
| 盘口/融合权重 | `config/settings.yaml` → `predictions.odds_blend_weight` |
| 预期 xG 说明 | `data/expected_xg/README.md`、`docs/赛前预期xG-数据来源与格式.md` |

## 四、出问题时

- **「未设置 THE_ODDS_API_KEY」**：在 `config/odds_api_key.txt` 里写一行你的 Key（参考 `config/odds_api_key.example.txt`），或设置环境变量 `THE_ODDS_API_KEY`。
- **拉盘口报 SSL 错误**：已用 certifi 修复；若仍报错，执行 `.venv/bin/pip install certifi`。
- **拉盘口报 422**：脚本已改为 `regions=eu`、`markets=h2h`，一般无需再改。
- **桌面点「拉取盘口」没反应**：看桌面下方日志；确认 `config/odds_api_key.txt` 存在且有一行有效 Key。

更多细节见项目根目录 [README.md](../README.md)。
