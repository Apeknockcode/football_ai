# 数据采集与整合

本文档约定 xG、伤停、赔率等数据的来源、存储格式与目录结构，便于脚本与人工维护一致、支撑 ML 与价值判断。

---

## 一、目录约定

在项目 `data/` 下建议使用以下子目录（可选，与现有 `data/expected_xg_teams.csv`、`data/<日期>/todays_injuries/` 等并存）：

| 目录 | 用途 |
|------|------|
| `data/expected_xg/` | 按赛季或按日存放预期 xG 表（按球队或按场次 CSV），便于多源整合 |
| `data/odds/` | 按日或按联赛存放赔率快照 CSV，支持时序与赔率变化分析 |
| `data/injuries/` | 统一格式的伤停 CSV（多源合并后），可选与 `data/<日期>/todays_injuries/` 联动 |

现有入口保持不变：赛前报告与预测仍可通过 `--expected-xg data/expected_xg_teams.csv`、`--odds <path>`、`--injuries <path>` 或 `data/<日期>/todays_injuries/` 使用。

---

## 二、xG 数据

### 来源与格式

- **按球队**：见 [赛前预期xG-数据来源与格式.md](赛前预期xG-数据来源与格式.md)。列：`team`, `xg`, `xg_home`, `xg_away`, `season`（可选）。
- **按场次**：列：`round`, `home_team`, `away_team`, `xg_home`, `xg_away`, `match_code`（可选）, `xg_ht_home`, `xg_ht_away`（可选）。

### 脚本入口

- **fetch_expected_xg**：从 Understat/FotMob 等拉取当季球队 xG（主/客），写入 `data/expected_xg_teams.csv` 或 `data/expected_xg/<league>_<season>.csv`。具体脚本见 `scripts/` 下 `fetch_expected_xg_*.py`（见下文）。

---

## 三、伤停数据

### 统一 CSV 列（便于多源合并）

| 列名 | 说明 |
|------|------|
| team | 队名，与报告/赛程一致 |
| player | 球员名 |
| reason | 受伤/停赛/出战成疑/缺阵/其他原因等 |
| source | 可选，来源标识（如 manual、ocr、api） |
| updated_at | 可选，更新日期或时间（YYYY-MM-DD 或 ISO） |

现有 `todays_injuries` 下 CSV 已使用 `team`, `player`, `reason`（或 `type`），与上述兼容；新增 `source`、`updated_at` 为可选，便于合并与去重。

### 脚本与来源

- 伤停仍以人工整理 + OCR（`scripts/parse_injury_images.py`、桌面端「保存图片并识别」）为主。
- 可选：轻量爬虫或 API 拉取一家稳定来源，写入 `data/injuries/` 或与 `data/<日期>/todays_injuries/` 合并，格式遵循上表。

## 四、赔率数据

### 存储格式（支持时序）

单文件 CSV 建议包含以下列（列名可兼容现有 `load_odds_for_match`）：

| 列名 | 说明 |
|------|------|
| date | 日期 YYYY-MM-DD，用于时序与赔率变化 |
| match_id | 可选，场次唯一标识 |
| home_team | 主队名 |
| away_team | 客队名 |
| round | 可选，轮次 |
| match_code | 可选，竞彩场次 |
| odds_home | 主胜欧洲小数赔率 |
| odds_draw | 平局欧洲小数赔率 |
| odds_away | 客胜欧洲小数赔率 |

同一场比赛可有多次记录（不同 `date`），用于分析赔率变化；报告与价值判断时通常取最近一条或指定日期。

### 脚本入口

- **fetch_odds**：从 [The Odds API](https://the-odds-api.com) 拉取五大联赛 1X2 赔率并**合并到赛程 CSV**（为每场添加 `odds_home`, `odds_draw`, `odds_away`）。需设置环境变量 `THE_ODDS_API_KEY`（免费档约 500 次/月）。用法：`python scripts/fetch_odds.py --csv data/<日期>/todays_matches.csv` 或 `--date YYYY-MM-DD`。合并后的 CSV 可直接被 `predict_batch` 与盘口参考（`config/settings.yaml` 中 `odds_blend_weight`）使用。
- **snapshot_odds**：按日或按场次拉取/录入赔率到 `data/odds/<date>.csv` 或 `data/odds/<league>_<date>.csv`。具体脚本见 `scripts/snapshot_odds.py`（见下文）；若无稳定数据源可先提供占位脚本与格式说明，由人工填写 CSV。

---

## 五、脚本清单

| 脚本 | 说明 |
|------|------|
| `scripts/fetch_expected_xg_understat.py` | 从 Understat 拉取当季联赛球队 xG（主/客），输出按球队 CSV |
| `scripts/snapshot_odds.py` | 赔率快照：按日或按场次写入 `data/odds/`，格式见上；可为占位 + 格式说明 |

伤停暂无独立拉取脚本，以格式约定与现有 OCR/人工流程为主。

---

## 六、与现有功能的衔接

- **赛前报告 / 预测**：继续使用 `--expected-xg`、`--odds`、`--injuries` 或桌面端选择；新目录下的文件可按需作为上述参数路径。
- **价值机会与赔率对比**：当存在赔率数据时，报告与批量预测会使用「模型概率 vs 赔率隐含概率」及价值方向指示；赔率来自 `data/odds/` 或既有 CSV。
- **ML 训练**：历史 pl_*.csv 已含 xg_home/xg_away；若未来特征需要伤停数量、赔率隐含概率等，可从上述目录与格式读取。
