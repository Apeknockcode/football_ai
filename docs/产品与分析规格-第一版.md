# AI 足球分析 · 产品与分析规格（第一版）

**版本**：V1  
**适用赛事**：英超（English Premier League）  
**文档目的**：界定第一版功能边界、名词含义与报告输出形态，供产品与开发对齐使用。

---

## 一、第一版做啥

### 1.1 分析维度

| 维度 | 说明 | 第一版实现程度 |
|------|------|----------------|
| **战术** | 阵型、压迫、转换、控球区域、强弱侧、关键套路 | 基于事件/阵型数据，输出指标与文字小结 |
| **伤停** | 缺阵、复出、累计黄牌、对阵容/战术的影响 | 以公众号等非结构化源为主，可辅以人工；预留结构化接口 |
| **政治** | 见下四子项 | 四块都覆盖，实现深度可分阶段 |
| ↳ 赛事/国家 | 德比、轮次重要性、赛事阶段 | 规则+元数据，优先实现 |
| ↳ 纪律/裁判 | 禁赛、争议、主裁风格（出牌/点球倾向） | 半结构化数据，与伤停同期 |
| ↳ 舆论/叙事 | 媒体叙事线（如「生死战」「复仇」） | 关键词/摘要，在纪律之后 |
| ↳ 俱乐部/帅位 | 帅位压力、管理层/更衣室相关背景 | 可简化或延后，依赖舆情/NLP |

### 1.2 报告形态

- **类型**：赛前报告、赛后报告（可先做其一或同步做）。
- **受众**：内部分析师（完整版）、球迷（摘要/故事版）；同一分析结果，两种呈现。
- **语言**：仅中文。
- **生成方式**：战术/伤停/政治各模块产出结构化或半结构化结论 → 模板 + 可选 LLM 润色 → 中文报告。

### 1.3 数据与赛事

- **赛事**：仅英超（含当季联赛轮次，不含足总杯/联赛杯等，除非后续 explicitly 纳入）。
- **战术数据**：建议优先用 StatsBomb（含开放数据）做 MVP；若选定其他供应商，按该供应商 schema 适配。
- **伤停**：当前以微信公众号等非结构化来源为主；预留接口便于后续接入官网或数据商。
- **新闻/舆论**：以国外信源为主（英超）；信源设计为可配置，便于日后扩展国内联赛。

## 二、第一版不做啥（边界）

以下在第一版**明确不做**或**不承诺**，避免范围蔓延。

### 2.1 赛事与数据

- **不做**其他联赛/赛事（如欧冠、西甲、中超）的正式支持；可预留扩展点，但不实现。
- **不做**比赛视频输入（无视频理解、无基于画面的事件识别）；仅基于结构化/半结构化数据。
- **不做**实时直播流分析（仅支持赛前/赛后，非实时）。

### 2.2 功能

- **不做**预测类产品（不输出胜负预测、比分预测、阵容推荐等）；仅做「已发生/已知信息的分析与报告」。
- **不做**博彩/赔率相关分析或任何与投注建议相关的输出。
- **不做**球员转会估值、身价、商业代言等与「战术+伤停+政治」无关的模块。

### 2.3 政治与合规

- **不做**对地区、种族、政治立场的价值判断或主观评价；仅做客观标签与事实性背景（如「国家德比」）。
- **不做**未经信源标注的断言；政治相关表述需可追溯（如「据 XX 报道」「官方公告」）。
- **不承诺**俱乐部/帅位、舆论/叙事在首版达到全自动、高准确率；可提供简化版或人工辅助。

### 2.4 产品形态

- **不承诺**多语言报告（第一版仅中文）。
- **不承诺** API 对外发布、移动端 App、实时推送；第一版以「生成报告文档/内容」为主，交付形态可再定（如 PDF、网页、内部看板）。

## 三、名词表

便于报告表述一致、开发与产品对齐；按模块分组。

### 3.1 战术相关

| 名词 | 含义 | 备注 |
|------|------|------|
| 阵型 | 球队整体站位形状（如 4-3-3、3-5-2） | 可为实际识别或数据商提供 |
| 压迫 | 无球时对对手的逼抢强度与范围（如高位逼抢、中位压迫） | 可用 PPDA、防守线高度等指标辅助 |
| 转换 | 由守转攻/由攻转守的节奏与成功率 | 可含丢失球权后的反抢、反击次数等 |
| 控球区域 | 控球与传球发生的区域分布（如左/中/右、前场/后场） | 可用分区统计或热区 |
| 强弱侧 | 进攻侧重的一侧或对手薄弱一侧 | 基于传球/推进方向等 |
| xG | 预期进球（Expected Goals） | 射门质量加权，数据商或自建模型 |
| 事件/事件流 | 比赛中发生的可记录动作（传球、射门、犯规等）及其序列 | 战术分析的基础数据 |

### 3.2 伤停与纪律

| 名词 | 含义 | 备注 |
|------|------|------|
| 伤停 | 因伤病或停赛无法出场 | 报告中使用「缺阵」「复出」等 |
| 累计黄牌 | 再得一张黄牌将停赛（视赛事规则） | 需按英超规则说明 |
| 禁赛 | 因红牌或累计黄牌等规则导致的停赛 | 与伤病因区分 |
| 主裁风格 | 该裁判历史出牌、点球等统计倾向 | 仅作客观描述，不做主观评价 |

### 3.3 政治四块

| 名词 | 含义 | 备注 |
|------|------|------|
| 赛事/国家背景 | 德比、恩怨、赛事阶段（如争四、保级）、国家/地区意义 | 规则表 + 元数据 |
| 纪律/裁判 | 与当轮相关的禁赛、争议判罚、主裁信息 | 见上 3.2 |
| 舆论/叙事 | 媒体与球迷的主流叙事线（如「生死战」「复仇」「纪录」） | 关键词或摘要 |
| 俱乐部/帅位 | 主帅压力、续约/下课传闻、管理层态度、更衣室相关 | 需标注信源 |

### 3.4 报告与产品

| 名词 | 含义 | 备注 |
|------|------|------|
| 赛前报告 | 比赛开始前生成的简报（阵容预期、伤停、政治背景、战术预期） |  |
| 赛后报告 | 比赛结束后生成的复盘（战术执行、关键事件、政治/舆论点评） |  |
| 完整版 | 面向内部分析师，含指标、方法论与数据支撑 |  |
| 摘要/故事版 | 面向球迷，结论清晰、叙事顺、少术语 |  |

## 四、输出示例

以下为**示意性**片段，非最终版式；用于说明各维度在报告中的呈现方式。

### 4.1 赛前报告（片段）

**—— 赛事与背景（政治 · 赛事/国家）**  
本场为英超第 28 轮，传统「双红会」（曼联 vs 利物浦），当前分列第 6 与第 2，涉及争四与争冠叙事。

**—— 伤停与纪律（伤停 + 政治 · 纪律/裁判）**  
- 缺阵：主队 [A]、[B] 伤缺；客队 [C] 停赛。  
- 主裁：[姓名]，本赛季场均出示 X.X 张黄牌，点球判罚略高于联赛平均。

**—— 战术预期（战术）**  
主队近期多以 4-2-3-1 出战，压迫强度中等；客队常用 4-3-3，前场逼抢积极。结合主客与伤停，预计主队侧重控球与边路，客队侧重转换与中路推进。

**—— 舆论与压力（政治 · 舆论/叙事 + 俱乐部/帅位）**  
媒体普遍将本场视为主队「必须拿分」的一战；客队主帅近期帅位稳固，暂无下课压力。（据 [信源]）

---

### 4.2 赛后报告（片段）

**—— 战术复盘（战术）**  
实际阵型主队 4-2-3-1、客队 4-3-3。主队控球率 XX%，但前场压迫不足，客队由守转攻成功次数明显更高；进攻侧重主队左路、客队右路，与赛前预期基本一致。xG 主 X.X – 客 X.X，客队创造机会质量更优。

**—— 关键事件**  
第 X 分钟 [事件]；第 Y 分钟 [事件]（可引用事件类型与时间，便于追溯）。

**—— 背景与叙事（政治）**  
本场结果对争四/争冠形势影响 [简述]。赛后舆论多聚焦 [主题]；主队帅位压力 [维持/上升]（据 [信源]）。

---

### 4.3 球迷摘要版（同一场 · 短版）

**赛前**：双红会，第 28 轮。主队 [A][B] 缺阵，客队 [C] 停赛。预计主队控球为主、客队反击威胁大。  
**赛后**：客队 X–X 取胜，转换与机会质量占优；主队压迫不足、左路虽活跃但效率一般。本场后 [争四/争冠] 形势 [简述]。

## 五、实现优先级（建议）

| 顺序 | 内容 | 说明 |
|------|------|------|
| 1 | 战术数据管道 + 基础指标（英超、StatsBomb 或已选供应商） | 事件/阵型 → 指标与小结 |
| 2 | 伤停模块（公众号试点或半自动 + 预留接口） | 与报告中的「缺阵/复出」对接 |
| 3 | 政治 · 赛事/国家 + 纪律/裁判 | 规则与半结构化数据 |
| 4 | 报告生成（整合战术+伤停+政治，仅中文） | 模板 + 可选 LLM，完整版 + 摘要版 |
| 5 | 政治 · 舆论/叙事 → 俱乐部/帅位 | 关键词/摘要与信源标注，可部分延后 |
