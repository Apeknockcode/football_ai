# 杯赛历史数据 · 如何维护

杯赛（足总杯、欧冠、欧联、联赛杯）可从 **FBref** 自动抓取，或手工维护 CSV 后做**校准**与**回测**。

---

## 1. 目录与文件

- 每个杯赛一个目录：`data/historical/{杯赛id}/`
  - 欧冠：`data/historical/UCL/`
  - 足总杯：`data/historical/FA_Cup/`
  - 欧联：`data/historical/UEL/`
  - 联赛杯：`data/historical/League_Cup/`
- 每赛季一个 CSV，命名：`pl_YYYY.csv`（与联赛一致，YYYY 为赛季结束年）
  - 例：2023/24 赛季 → `pl_2024.csv`

---

## 2. CSV 格式（与联赛相同）

**必选列**（表头必须一致）：

| 列名 | 说明 | 示例 |
|------|------|------|
| season | 赛季结束年 | 2024 |
| round | 轮次（见下） | 7 |
| home_team | 主队名 | Real Madrid |
| away_team | 客队名 | Manchester City |
| xg_home | 主队 xG | 1.85 |
| xg_away | 客队 xG | 1.42 |
| goals_home | 主队实际进球 | 3 |
| goals_away | 客队实际进球 | 3 |

- 编码：**UTF-8**
- 队名：与报告里使用的名称一致（中文或英文均可，校准/回测不依赖语言，报告用队名映射时可配）

**轮次 round 建议**（与 `config/cups.yaml` 里 `stage_labels` 对应即可）：

- **欧冠 UCL**：1–6 小组赛第1–6轮，7 1/8决赛，8 1/4决赛，9 半决赛，10 决赛
- **足总杯 FA_Cup**：1–3 第1–3轮，再往后可自定（如 4 第4轮、5 1/8、6 1/4、7 半决赛、8 决赛）
- **欧联 UEL**：可仿照欧冠自定
- **联赛杯 League_Cup**：按轮次从 1 开始编号即可

---

## 3. 自动拉取（FBref）

在项目根目录执行（依赖 pandas，会请求 fbref.com）：

```bash
# 欧冠 2024/25 赛季
./run.sh fetch cup UCL 2025

# 欧联 2024、2025 两季
./run.sh fetch cup UEL 2024 2025

# 足总杯、联赛杯
./run.sh fetch cup FA_Cup 2025
./run.sh fetch cup League_Cup 2025
```

- 若本机报 **SSL 证书错误**，可设 `FBREF_NO_SSL_VERIFY=1` 再运行（仅限本地）。
- 若遇到 **403 Forbidden**（FBref 限制非浏览器访问），可在浏览器打开对应赛程页（如 [欧冠赛程](https://fbref.com/en/comps/8/2024-2025/schedule/2024-2025-Champions-League-Scores-and-Fixtures)），「另存为」完整网页，再执行：
  ```bash
  .venv/bin/python scripts/fetch_historical_fbref_cups.py --cup UCL --season 2025 --html 你保存的网页.html
  ```
- 抓取结果写入 `data/historical/UCL/pl_2025.csv` 等，格式与下文「手工维护」一致。

## 4. 操作步骤（手工维护）

### 4.1 新建杯赛目录和文件

```bash
mkdir -p data/historical/UCL
```

复制模板（仅表头）或从 `_common/cup_season_template.csv` 复制后改名：

```bash
# 表头 + 示例行在 _common/cup_season_template.csv，可复制后清空示例、保留表头再填
cp data/historical/_common/cup_season_template.csv data/historical/UCL/pl_2024.csv
```

用 Excel / Numbers / 文本编辑器打开 `data/historical/UCL/pl_2024.csv`，**保留第一行表头**，从第二行起每行一场比赛。

### 4.2 数据从哪里来

- **比分**：官网、维基、FBref 等均可。
- **xG**：FBref、Understat（若有该杯赛）、其他数据站；若没有 xG 可先填 0 或同填实际进球作占位，仅做校准时会影响缩放，但可先跑通流程。

示例（一行一场）：

```csv
season,round,home_team,away_team,xg_home,xg_away,goals_home,goals_away
2024,7,Real Madrid,Manchester City,1.85,1.42,3,3
2024,7,Bayern Munich,Arsenal,1.62,1.18,2,2
```

### 4.3 保存与校验

- 存成 **UTF-8** CSV。
- 确认列名与上表一致、无多余列（可选列如 `ht_goals_home` 可加，见 [data/historical/README.md](data/historical/README.md)）。

### 4.4 生成校准与回测

有至少若干场数据后：

```bash
# 校准：生成 config/calibration_UCL.yaml
./run.sh calibrate --league UCL

# 回测：用该校准逐场预测，看 Brier、对数似然
./run.sh backtest --league UCL
```

若未指定 `--historical`，脚本会从 `data/historical/UCL/` 下所有 `*.csv` 读入。

---

## 5. 多赛季

- 同杯赛多赛季：同一目录下多个文件即可，例如  
  `data/historical/UCL/pl_2023.csv`、`pl_2024.csv`、`pl_2025.csv`  
  校准/回测会读取该目录下全部 CSV。
- 不同杯赛互不干扰：足总杯在 `FA_Cup/`，欧冠在 `UCL/`，各自维护、各自 `--league FA_Cup` / `--league UCL` 做校准与回测。

---

## 6. 小结

| 步骤 | 操作 |
|------|------|
| 1 | 建目录 `data/historical/UCL/`（或 FA_Cup、UEL、League_Cup） |
| 2 | 新建或复制 `pl_YYYY.csv`，表头为上述必选列，UTF-8 |
| 3 | 每行一场，填 season、round、主客队、xG、比分 |
| 4 | 运行 `./run.sh calibrate --league UCL` 生成校准 |
| 5 | 运行 `./run.sh backtest --league UCL` 做回测 |

两回合、点球、晋级概率等为后续扩展；当前仅支持「单场」历史记录与单场校准/回测。
