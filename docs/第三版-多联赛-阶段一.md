# 第三版 · 多联赛（阶段一）已完成

按「联赛 → 杯赛 → 国家队」三阶段规划，阶段一为**多联赛 + 同国不同层级**。

## 已实现

1. **联赛配置**  
   - `config/leagues.yaml`：联赛 id、name_zh、name_en、understat_code。  
   - 当前支持：EPL、La_Liga、Bundesliga、Serie_A、Ligue_1、Championship（英冠暂无 Understat 代码，可手工维护数据）。

2. **数据按联赛分目录**  
   - 历史数据：`data/historical/{league_id}/pl_YYYY.csv`。  
   - 原 `data/historical/pl_*.csv` 在首次对 EPL 抓取时会复制到 `data/historical/EPL/`，避免丢失。

3. **校准与回测按联赛**  
   - 校准输出：`config/calibration_{league_id}.yaml`（如 `calibration_EPL.yaml`）。  
   - `./run.sh calibrate [--league EPL]`、`./run.sh backtest [--league EPL]`；不指定时默认 EPL。

4. **抓取按联赛**  
   - `./run.sh fetch 2024 2025`：EPL 多赛季。  
   - `./run.sh fetch La_Liga 2024 2025`：西甲多赛季。  
   - 脚本 `scripts/fetch_historical_understat.py` 支持 `--league`，写入 `data/historical/{league_id}/`。

5. **报告与预测按联赛**  
   - CLI：`--league EPL`（默认 EPL）；报告内「本场为英超第 N 轮」等由联赛 name_zh 决定。  
   - 预测使用的校准文件由 `league_id` 选择。

## 使用示例

```bash
# 拉取 EPL 2024、2025 赛季
./run.sh fetch 2024 2025

# 校准 EPL，生成 config/calibration_EPL.yaml
./run.sh calibrate --league EPL

# 回测 EPL
./run.sh backtest --league EPL

# 赛前报告（英超）
./run.sh pre --league EPL --home 阿森纳 --away 切尔西 --round 15 --xg-home 1.8 --xg-away 1.2
```

## 阶段二：杯赛（已实现）

- **配置**：`config/cups.yaml` 定义杯赛 id、name_zh、two_legged、stage_labels（轮次→文案）。
- **报告**：`--league UCL` 等可指定杯赛，展示如「本场为欧冠1/8决赛」；预测与校准可沿用单场 Poisson，杯赛无历史数据时可不使用校准。
- **数据**：历史数据可放在 `data/historical/UCL/`、`data/historical/FA_Cup/` 等，格式与联赛 CSV 一致；杯赛暂无 Understat 抓取，需手工维护或后续接入。
