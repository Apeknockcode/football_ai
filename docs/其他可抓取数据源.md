# 其他可抓取/可用的足球数据源

除当前已接入的 **Understat** 与 **FBref** 外，以下网站或 API 也可提供联赛赛果、xG 等数据，便于第四版多维度参考时扩展。

---

## 一、已接入（当前项目）

| 来源 | 用途 | 说明 |
|------|------|------|
| **Understat** | 联赛历史赛果 + xG | `./run.sh fetch EPL 2026`，五大联赛等，有 understat_code 即支持 |
| **FBref** | 联赛/杯赛赛程 + xG | `./run.sh fetch fbref EPL 2026`、`./run.sh fetch cup UCL 2025`，需配置 fbref_comp_id/fbref_slug |
| **FotMob**（soccerdata） | 联赛赛程 + 每场 xG | `./run.sh fetch fotmob EPL 2026`，需配置 fotmob_league_id，依赖 soccerdata |
| **Football-Data.co.uk** | 赛果 + 赔率，无 xG | `./run.sh fetch fd EPL 2025`，直链 CSV，支持 EPL/Championship/西甲/德甲/意甲/法甲 |
| **Sofascore**（soccerdata） | 赛程、积分表、比分 | `./run.sh fetch sofascore EPL 2025`，依赖 soccerdata |
| **ESPN**（soccerdata） | 赛果、统计、阵容 | `./run.sh fetch espn EPL 2025`，依赖 soccerdata |
| **WhoScored**（soccerdata） | 赛果、预览、事件流 | `./run.sh fetch whoscored EPL 2025`，依赖 soccerdata + Selenium，反爬较严 |

## 二、可扩展接入（免费、可抓取或开源库支持）

### 1. FotMob（fotmob.com）

- **数据**：赛程、比分、**每场 xG**（Expected goals）、传球、控球等球队比赛统计。
- **覆盖**：五大联赛、欧冠等，与 FBref 类似。
- **获取方式**：  
  - 使用 Python 库 **soccerdata**（`soccerdata.FotMob`）可读联赛、赛季、赛程及球队比赛统计（含 xG）。  
  - 也可自行请求 FotMob 前端使用的 API（需遵守其使用条款与访问频率）。
- **与现有流程**：可仿照 FBref 写 `fetch_historical_fotmob_leagues.py`，输出 `pl_YYYY_fotmob.csv`，再在合并脚本中支持「Understat + FBref + FotMob」三源合并。

### 2. Sofascore（sofascore.com）

- **数据**：赛程、比分、联赛积分表、阵容等；也有 xG 等高级数据（具体以页面/API 为准）。
- **获取方式**：**soccerdata** 提供 `soccerdata.Sofascore`，可读联赛表、赛程等。
- **与现有流程**：同样可做成第三数据源，输出 `pl_YYYY_sofascore.csv` 参与合并。

### 3. ESPN（espn.com/soccer）

- **数据**：历史赛果、统计、阵容等。
- **获取方式**：**soccerdata** 的 `soccerdata.ESPN`。
- **说明**：适合补全赛程/比分，xG 需看 ESPN 当前是否暴露在可抓取页或 API 中。

### 4. WhoScored（whoscored.com）

- **数据**：赛果、赛事预览、详细事件流（Opta 系）。当前 schedule 只含比分，xG 为占位 0。
- **获取方式**：**soccerdata** 的 `soccerdata.WhoScored`，需 **Selenium**（Chrome/Firefox + webdriver）。
- **命令**：
  - 单联赛：`./run.sh fetch whoscored EPL 2025`
  - 五大联赛：`./run.sh fetch whoscored all 2025`
- **说明**：反爬较严，抓取较慢（每联赛数分钟）；输出 `pl_YYYY_whoscored.csv` 含真实比分，可与 Understat 合并补缺。

### 5. Football-Data.co.uk

- **数据**：历史赛果、**博彩赔率**、部分联赛的基础比赛统计（如射门、角球等），不同联赛详细程度不同。
- **获取方式**：**soccerdata** 通过 `MatchHistory`（Football-Data.co.uk）读取；也可直接下载站内 CSV。
- **说明**：无 xG，但可与现有 xG 数据结合做赔率/校准对比。

## 三、付费 API（需订阅，禁止爬站）

| 来源 | 说明 | 备注 |
|------|------|------|
| **FootyStats** (footystats.org) | 提供 xG、710+ 数据点/队，约 1500+ 联赛 | API 订阅制（如 £29.99/月起），禁止爬取网站 |
| **Sportmonks** | 足球 API 含 xG 端点 | 有免费试用，正式使用需付费 |
| **ExpectedScore** | xG 等数据 API | 仅允许通过官方 API，禁止爬取 |
| **API-FOOTBALL / Football-Data.org** | 赛程、比分、部分统计 | 免费档有调用限制，适合补全赛程/比分 |

若只做「多网站联赛数据参考」，优先扩展 **FotMob**（含每场 xG、soccerdata 已支持）即可多一个免费维度；再按需考虑 Sofascore、ESPN 等补赛程或比分。

## 四、soccerdata 库参考

安装与示例：

```bash
pip install soccerdata
```

```python
import soccerdata as sd

# FotMob：西甲 2022/23，含赛程与球队比赛统计（含 xG）
fotmob = sd.FotMob(leagues="ESP-La Liga", seasons="2022/2023")
schedule = fotmob.read_schedule()           # 赛程、比分
match_stats = fotmob.read_team_match_stats() # 每场统计，含 Expected goals (xG)

# Sofascore：赛程与积分表
sofascore = sd.Sofascore(leagues="ESP-La Liga", seasons="2022/2023")
schedule = sofascore.read_schedule()
```

联赛 ID 格式与 FBref/Understat 不同（如 `ESP-La Liga`），接入时需在 `config/leagues.yaml` 或映射表中维护各源的联赛 ID。

## 五、小结

- **已用**：Understat + FBref，支持多源合并（`merge`）。
- **建议优先扩展**：**FotMob**（有每场 xG、soccerdata 支持），可作为第三源写入 `pl_YYYY_fbref.csv` 同目录下的 `pl_YYYY_fotmob.csv`，再扩展合并脚本支持三源。
- **其他**：Sofascore、ESPN、WhoScored、Football-Data.co.uk 可按需做赛程/比分或事件级补充；付费 API 仅在需要官方授权数据时考虑。

所有抓取行为请遵守各站点的使用条款与访问频率，仅供个人/教育用途。
