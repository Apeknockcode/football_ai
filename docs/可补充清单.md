## 功能扩展（可选）

- [x] **赛程表与预期 xG 按竞彩场次**：赛程表可含 `match_code`/竞彩场次列；CLI 支持 `--match-code 周五012` 与 `--fixtures`，从赛程解析主客队、轮次、时间。预期 xG 按场次表可含 `match_code` 列，按场次匹配时优先用 match_code。

- [x] **LLM 润色**：`config/settings.yaml` 中 `report.llm` 可配置 `enabled`、`provider`（如 openai）、`api_key`（或环境变量 OPENAI_API_KEY）、`model`；CLI 加 `--llm` 即对报告调用 OpenAI 润色（保持事实与数字不变）。

## 多维度分析（第四版补充）

- [x] **近期状态**：`football_ai.data.form.get_team_form`，近 5 场胜负、进失球、积分；报告【近期状态与交锋】。
- [x] **历史交锋**：`football_ai.data.h2h.get_h2h`，同对主客队交锋记录；报告同上。
- [x] **传统统计与 xPts**：`football_ai.data.team_stats.get_team_season_stats`，赛季胜率、场均进失球、实际积分与预期积分 xPts（xGA 聚合）；报告【积分与预期】。
- [x] **赔率对比**：`football_ai.data.odds`，仅做「模型概率 vs 赔率隐含概率」对比展示，不构成投注建议；CLI `--odds` 或 `--odds-home/--odds-draw/--odds-away`。
- [x] **Elo**：`football_ai.data.elo.get_elo_for_report`，基于历史场次更新 Elo，报告【Elo 参考】。
- [x] **ML 特征与训练**：`football_ai.ml.features.build_dataset` 构建特征（xG、近期、赛季、H2H、Elo）；`scripts/train_ml.py` 训练胜负平分类模型并保存。需安装 `scikit-learn`（见 requirements 注释）。

以上均需在生成报告时提供 `--historical`（历史 CSV 或目录）及可选 `--season`、`--league`。
