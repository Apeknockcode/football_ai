# 第三版 · 杯赛（阶段二）已完成

阶段二为**杯赛**：足总杯、欧冠、欧联、联赛杯等，支持淘汰赛阶段文案与单场预测。

## 已实现

1. **杯赛配置**  
   - `config/cups.yaml`：id、name_zh、name_en、two_legged、stage_labels（轮次→展示文案，如欧冠 7→「1/8决赛」）。

2. **赛事统一解析**  
   - `get_competition(competition_id)`：先查联赛再查杯赛，返回带 `type: league | cup` 的配置。  
   - `get_competition_type(competition_id)`、`get_calibration_path`、`get_historical_dir` 均支持联赛与杯赛 id。

3. **报告展示**  
   - `--league UCL` 等：赛事名称用杯赛 name_zh，轮次用 stage_labels（若有）否则「第 N 轮」，例如「本场为欧冠1/8决赛」。

4. **数据与校准**  
   - 历史数据可放在 `data/historical/UCL/`、`data/historical/FA_Cup/` 等，CSV 格式与联赛一致。  
   - 若有历史 CSV，可 `./run.sh calibrate --league UCL` 生成 `config/calibration_UCL.yaml`。  
   - 杯赛无 Understat 代码，抓取脚本不提供在线拉取，需手工维护或后续接入其他数据源。

5. **预测**  
   - 单场仍用 Poisson(xG)，若有该校赛事的校准文件则自动加载；无则按原始 xG 计算。

## 使用示例

```bash
# 欧冠 1/8 决赛赛前报告
./run.sh pre --league UCL --home 皇马 --away 曼城 --round 7 --xg-home 1.5 --xg-away 1.2

# 足总杯第 3 轮
./run.sh pre --league FA_Cup --home 曼联 --away 利物浦 --round 3 --xg-home 1.2 --xg-away 1.4
```
